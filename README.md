# Pratham Grover — Personal Portfolio

A responsive personal portfolio card built with HTML and CSS. It introduces Pratham Grover, highlights his interests and experience, and provides links to his GitHub, LinkedIn, and email.

## Live site

[View the portfolio on Vercel](https://personal-portfolio-ten-tau-88.vercel.app/)

## Features

- Responsive layout for desktop and mobile screens
- Profile photo and short introduction
- Education, interests, and selected experience highlights
- Links to GitHub, LinkedIn, and email
- Custom cybersecurity-themed shield and circuit illustration
- CSS hover effects and keyboard-visible focus styles

## Project files

- `index.html` — page content and structure
- `styles.css` — layout, styling, and responsive behavior
- `profile-photo.jpg` — profile image used on the page

## View locally

Download or clone the project, then open `index.html` in a web browser. The page uses no build tools or package dependencies. The web fonts are loaded from Google Fonts, with fallback fonts specified in the stylesheet.

## Deployment

The project is deployed on Vercel at the link above. To deploy your own copy, import the project’s GitHub repository into Vercel, select **Other** as the framework preset, and serve the folder containing `index.html` and `styles.css` as the output directory.
